# D. a11y

У нас есть сайт вакансий для поиска специалистов. Мы хотим с его помощью найти эксперта по доступности, но в процессе замечаем, что сам сайт совершенно не соответствует стандартам a11y. Мы принимаем важное и благородное решение — улучшить его доступность для всех пользователей, в том числе для людей с особыми потребностями.

Ваша задача — найти и исправить ошибки доступности в этом HTML-коде: [скачать index.html](./index.html).

## Примечание

Не меняйте текстовый контент документа, разрешено работать только с тегами и их атрибутами. Id тоже важно сохранить.

В качестве решения вам нужно отправить файл с разрешением `.html`.
