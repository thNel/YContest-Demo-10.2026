# I. Этапы CI/CD

Процесс CI/CD (Continuous Integration / Continuous Deployment) — это основа современной автоматизированной доставки кода. Поэтому важно понимать последовательность его этапов.

Ваша задача — восстановить правильный порядок действий: что происходит после того, как разработчик отправил свой код в репозиторий.
