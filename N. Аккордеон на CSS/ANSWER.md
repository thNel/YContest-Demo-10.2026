# N. Аккордеон на CSS — пояснение решения

Интерактивность реализована только в `styles.css`. Разметка уже использует стандартные элементы HTML `<details>` и `<summary>`, поэтому JavaScript и дополнительные DOM-элементы не нужны.

## Переключение вопросов

Браузер сам переключает `<details>` при нажатии на вложенный `<summary>`. Атрибут `open` у первого вопроса задаёт начальное состояние. У всех вопросов указано одинаковое имя группы — `name="internship-faq"`: браузер оставляет в такой группе открытым не более одного `<details>`. Поэтому при открытии нового вопроса предыдущий закрывается автоматически.

CSS проверяет состояние через атрибут `[open]` и применяет нужные стили только к открытому пункту.

## Оформление открытого заголовка

Для `.faq__item[open] > .faq__question` задаются цвет текста и фон из переменных `--faq-active-color` и `--faq-active-background`.

Активный цвет явно задан и тексту `.faq__question-text`, и номеру `.faq__number` общим правилом. Плавный переход цвета для них также задан общим правилом; номеру он нужен, потому что в `base.css` для номера уже установлен собственный серый цвет.

Полоса нарисована псевдоэлементом `::before` заголовка. Она абсолютно позиционирована у левого края, поэтому не занимает место в сетке заголовка. В закрытом состоянии полоса сжата по вертикали (`scaleY(0)`), а в открытом растягивается (`scaleY(1)`). Цвет и ширина берутся из `--faq-active-stripe-color` и `--faq-active-stripe-width`.

Переходы цвета и фона заголовка, а также появление полосы занимают 300 мс.

## Иконка «+» и «×»

`.faq__icon` остаётся пустым элементом из HTML. Две CSS-линии создаются его псевдоэлементами `::before` и `::after`: первая расположена горизонтально, вторая повёрнута на 90 градусов. Вместе они образуют плюс.

У открытого пункта псевдоэлементы поворачиваются по отдельности: горизонтальная линия — на 45 градусов, вертикальная — на −45 градусов. Вместе они образуют крестик. `currentColor` задаёт цвет линий по текущему цвету заголовка, а `transition` плавно анимирует их поворот.

## Плавное раскрытие ответа

В `base.css` у `.faq__answer-clip` уже заданы `display: grid` и обрезка переполнения, а у внутреннего элемента — `min-height: 0`. Это позволяет анимировать единственную строку сетки от `0fr` до `1fr`:

- закрытый пункт: `grid-template-rows: 0fr`;
- открытый пункт: `grid-template-rows: 1fr`.

При `1fr` строка занимает естественную высоту содержимого. Поэтому ответ может содержать разное количество текста и не требует заранее заданной высоты. При закрытии анимация идёт обратно. Длительность перехода — 300 мс.

## Длительность анимаций

Все переходы заданы длительностью 300 мс: оформление заголовка, полоса, линии иконки и раскрытие ответа.
