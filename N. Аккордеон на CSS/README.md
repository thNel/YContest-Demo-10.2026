# N. Аккордеон на CSS

На странице находится список вопросов о стажировке. Внешний вид уже задан, но интерактивное поведение аккордеона не реализовано.

Ваша задача — реализовать аккордеон, изменяя только файл `styles.css`.

Изначально раскрыт первый вопрос. Нажатие на заголовок меняет состояние соответствующего вопроса; раскрытие нового вопроса закрывает предыдущий. Все сопровождающие изменения внешнего вида и расположения элементов должны происходить плавно. Ответ может иметь произвольную высоту и не должен обрезаться.

В пустом элементе иконки средствами CSS изобразите «+», который при раскрытии визуально превращается в «×».

Открытый вопрос должен визуально отличаться от остальных:

- цвет текста `.faq__question` — `var(--faq-active-color)`;
- фон заголовка — `var(--faq-active-background)`;
- вдоль левого края заголовка проходит сплошная полоса шириной `var(--faq-active-stripe-width)` и цветом `var(--faq-active-stripe-color)`.

## Формат ввода

Оригиналы файлов задачи находятся в подкаталоге `templates`:

- [index.html](templates/index.html) — разметка страницы;
- [base.css](templates/base.css) — базовые стили и внешний вид страницы;
- [styles.css](templates/styles.css) — исходный файл стилей с готовыми значениями цветов и ширины полосы.

## Формат вывода

В качестве решения принимается файл `styles.css`.

## Примечание

Изменять `index.html` и `base.css` нельзя.

Также запрещено использовать JavaScript, добавлять новые DOM-элементы, подключать библиотеки, внешние стили или другие ресурсы.
