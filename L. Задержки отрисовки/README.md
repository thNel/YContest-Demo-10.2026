# L. Задержки отрисовки

После релиза мониторинг собрал время отрисовки виджетов аналитического дашборда. Нужно найти максимальный разрыв между соседними значениями задержек.

## Условие

Функция получает единственный аргумент — ссылку на SVG-контейнер. Его непосредственные дочерние элементы `rect` представляют столбцы диаграммы; задержка хранится в атрибуте `data-value`.

Столбцы идут в произвольном порядке. Соседними считаются значения задержек, соседние после упорядочивания по возрастанию. Функция должна вернуть наибольшую разность между такой парой.

```javascript
function solution(container) {
    // ...
}
```

## Ограничения

- Значения `data-value` — целые неотрицательные числа.
- Столбцов не меньше двух; дубликаты возможны.
- Если все значения одинаковы, ответ равен `0`.
- Атрибуты `x`, `y`, `width` и `height` используются только для отображения.
- Решение выполняется в браузере.

## Пример

Для значений `20, 150, 60, 40, 80, 120, 100, 50` после упорядочивания получаем `20, 40, 50, 60, 80, 100, 120, 150`. Максимальный разрыв равен `30`.
