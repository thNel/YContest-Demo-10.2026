# Пояснительная записка: «Задержки отрисовки»

## Идея

Нужно найти максимальную разность между соседними значениями после сортировки. Сортировать весь массив можно за `O(n log n)`, но максимальный разрыв находится за `O(n)` с помощью корзин.

## Алгоритм

1. Одним проходом по непосредственным дочерним `rect` читаем `data-value`, сохраняем значения и находим минимум и максимум.
2. Если минимум равен максимуму, все значения одинаковы — возвращаем `0`.
3. Разбиваем диапазон `[min, max]` на корзины шириной `ceil((max - min) / (n - 1))`.
4. Для каждой корзины храним минимум и максимум попавших в неё значений.
5. Идём по корзинам слева направо. Для каждой непустой корзины сравниваем её минимум с максимумом предыдущей непустой корзины. Наибольшая такая разность — ответ.

## Почему это работает

Между `n` отсортированными значениями есть `n - 1` промежутков, сумма которых равна `max - min`. Поэтому хотя бы один промежуток не меньше среднего: `ceil((max - min) / (n - 1))`.

Ширина корзины равна этой величине. Поскольку значения целые, разница между двумя значениями внутри одной корзины строго меньше её ширины. Значит, максимальный промежуток не может целиком находиться внутри корзины: он проходит между соседними непустыми корзинами. Для такой пары достаточно знать максимум предыдущей и минимум следующей.

Например, для значений `20, 150, 60, 40, 80, 120, 100, 50` ширина корзины равна `ceil(130 / 7) = 19`. При просмотре непустых корзин наибольшая разность между соседними границами получается `150 - 120 = 30`.

## Сложность

- Время: `O(n)` — сбор значений, заполнение корзин и просмотр корзин.
- Дополнительная память: `O(n)`.

Селектор `:scope > rect` выбирает только непосредственные дочерние столбцы. Заголовки диаграммы и другие вложенные элементы в расчёт не попадают.
